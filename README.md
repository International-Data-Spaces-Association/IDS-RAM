# IDS RAM #

Welcome to the IDS RAM repository of the [IDSA](../../../idsa), the working repository used to create a new version of IDS-RAM with a modular approach.

## Overview ##

We are preparing a new edition of the IDS-RAM. Many key concepts and technical aspects of data spaces have advanced in recent months. These developments are not yet reflected in the current version, so the new edition will capture the latest results, including IDSA’s contributions to international standards and specifications.

The updated RAM will become the main reference for implementing the ideas defined in the IDSA Rulebook. It will translate governance models, data usage policies, and protocol specifications into clear logical components, defined interfaces, and consistent behavior patterns.

The new version aims to support interoperability, scalability, and conformance across different environments. Instead of prescribing a single approach, it will offer a structured design space that adapts to diverse needs while preserving the core IDSA data space model.


## Join the IDS RAM work ##

We are developing the next version of the Reference Architecture Model together with our community in the **IDSA Working Group Architecture**. 


## How to contribute ##

1 First, the fundamentals: Read the Manifesto of Data Spaces and the IDSA Rulebook in the [IDSA Knowledge Base](https://kb.internationaldataspaces.org/) to get some context.

2 Get in touch with [our team](mailto:ilknur.chulani@internationaldataspaces.org?subject=RAM) to get onboarded to **Working Group Architecture**, and get invited to the shared folders and the RAM Touch Point calls. To know more about the IDSA working groups, please visit [our home page](https://internationaldataspaces.org/we/working-groups/) and the [working groups brochure](https://internationaldataspaces.org/download/50753/?tmstv=1770728340).

3 Check the open [discussions](../../discussions), [issues](../../issues), [pull requests](../../pulls) in this repository. Add new inputs or review other contributions and add your comments in these.

4 Please also consider the following:

- [Code of Conduct](./CODE_OF_CONDUCT.md),
- [Contributing Guidelines](./CONTRIBUTING.md),
- [License](./LICENSE.md),
- [Changelog](./CHANGELOG.md)

## How to connect with others working on RAM ##

- Join the **RAM Touch-point calls** bi-weekly on Mondays at 10 CEST: This is the sync point for contributors and maintainers. 

- Attend the **[Quarterly Working Group meetings](https://internationaldataspaces.org/we/working-groups/)**: These are usually online events where the vision and next steps for RAM and other assets of the working group is discussed and the work completed in each quarter gets reviewed/approved by the WG members

The meetings are announced on the [IDSA events page](https://internationaldataspaces.org/events/) and included in the [IDSA Meetings calendar](https://github.com/International-Data-Spaces-Association/members-area/tree/main/Meetings%20Calendar). Please see [discussion #49](../../discussions/49) or [contact our team](mailto:ilknur.chulani@internationaldataspaces.org?subject=RAM) for more details.
